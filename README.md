# AI-Powered RAG & Document Assistant Backend

An advanced backend system built with **Python**, **FastAPI**, and modern AI libraries to process documents (PDFs/Text) and provide intelligent answers using Large Language Models (LLMs).

## 🚀 Features
- **Document Ingestion:** Automatically reads, parses, and chunks large PDF files.
- **Vector Search:** Uses Vector Databases to find relevant context quickly.
- **FastAPI Endpoints:** Clean, fast, and documented RESTful API endpoints for querying.
- **LLM Integration:** Connects seamlessly with OpenAI or Open-Source local models.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Framework:** FastAPI
- **AI/ML:** LangChain / LlamaIndex
- **Vector DB:** ChromaDB / FAISS
